# Git Workflow 

## Step-by-step flow:

1. Create repository
2. Clone repository
   git clone <repo-link>

3. Create new branch
   git checkout -b feature-branch

4. Make changes

5. Add changes
   git add .

6. Commit changes
   git commit -m "updated feature"

7. Push branch
   git push origin feature-branch

8. Create Pull Request on GitHub
